About BuckTagger

BuckTagger is a rule-based classifier of Arabic words into the morphological categories of Buckwalter's Arabic Morphological Analyzer (BAMA). This modern version brings the power of Arabic morphological analysis to any webpage as an embeddable component.

What it does

Classifies Arabic words (primarily imperfect verbs) into Buckwalter morphological categories. Returns primary tags and secondary (derived) forms automatically.

Modern Stack

Built with TypeScript and Web Components. Zero dependencies. Works with any framework or no framework. Embeddable anywhere with a single script tag.

Rule-Based

Uses morphological rules based on the Buckwalter tagset. Analyzes diacritics, root letters, and grammatical features to determine accurate classifications.

Arabic Morphology Knowledge

Comprehensive documentation in Arabic covering all morphological rules, tags, and examples from the original research.

How to Embed

Add BuckTagger to your website with just one line:

<!-- Include the script --> <script type="module" src="https://your-cdn.com/buck-tagger.es.js"></script> <!-- Use the component --> <buck-tagger></buck-tagger>

Installation via NPM

npm install buck-tagger // In your JavaScript import 'buck-tagger';
